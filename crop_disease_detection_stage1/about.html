ABOUT THE PROJECT

AI for practical crop disease detection.

This website is the front-end prototype for an academic project focused on using image processing and artificial intelligence to assist with crop disease identification.

◎

Project aim

To develop a system that can analyze crop images and assist users in identifying visible disease patterns through an AI-based image classification model.

⌁

Core technologies

Image processing, machine learning/deep learning, computer vision, a trained classification model, and a web-based user interface.

↗

Future integration

The upload interface will later communicate with a Python backend and trained model to produce real predictions.
